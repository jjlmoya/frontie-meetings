# Canción medieval

Materiales para la canción medieval. La mezcla completa `audio/Frontie the Feline King.mp3` y los 12 stems están en esta carpeta. Todos los stems decodifican a **142,032 s (2:22)** y mantienen el mismo inicio, por lo que están alineados.

- `audio/Frontie the Feline King.mp3`: mezcla completa para reproducción en la web.
- `stems/`: pistas separadas sincronizadas. Ya están batería, percusión, bajo, guitarra, teclado, cuerdas, sintetizador, metales, vientos, voces y otros.
- `layers/`: capas gráficas transparentes para animación. `concepto-gato-juglar.png` es la referencia visual corregida.
- `letra.md`: letra completa recibida para preparar los subtítulos.
- `video/preview-medieval.gif`: preview visual provisional de tres segundos.
- `video/`: aquí irá el MP4 final en bucle cuando esté montado.

No hace falta que unas los stems: sirven para guiar el baile. El MP3 completo es la pista que reproducirá la web.
